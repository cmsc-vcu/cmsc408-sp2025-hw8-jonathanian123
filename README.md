# CMSC 408 - Homework 8  
## 🌍 World Bank Indicator Analysis

This project is part of CMSC 408 (Spring 2025) and focuses on exploring and analyzing global development data using SQL and Python.

### 📄 Description

In this assignment, we:
- Connected to a MySQL database using environment variables.
- Explored and cleaned real-world country and region data from the World Bank.
- Wrote SQL queries to uncover trends and summarize regional economic indicators.
- Built insightful summary tables using advanced SQL features like `GROUP BY`, `JOIN`, `CASE`, and `CTEs`.
- Produced a fully reproducible report in Quarto format.

### 🔧 Technologies Used
- **SQL** (MySQL dialect)
- **Python** (via Quarto `.qmd` file)
- **SQLAlchemy & PyMySQL** (for database connections)
- **Pandas** (for data handling)
- **Quarto** (for integrated notebook-style reporting)
